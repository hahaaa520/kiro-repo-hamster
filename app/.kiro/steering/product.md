# product.md · 代码仓鼠

## 是什么
一个住在 GitHub 仓库里的电子宠物。输入用户名，3 秒领养；提交记录决定它的体重、心情、饥饿与亲密度；它会吐槽、会 emo、会离家出走；最新 diff 里的 bug 会被它藏进腮帮子；可生成分享卡；Kiro Agent Hook 保存代码即可投喂。

## 给谁
- 独立开发者 / 小团队 / 学生：想练手、做作品集、攒社交素材
- 现场评审：30 秒能理解、能上手玩自己的 GitHub
- 社交媒体上的程序员：体检报告适合晒

## 核心价值
- 情绪价值 > 工具价值：让「写代码」重新变得有点可爱
- 零门槛：不登录、不授权、只读公开仓库
- 传播性：名字是谐音梗、结果个人化、报告可分享
- Kiro 叙事：Spec 并行开发 + Agent Hook 成为产品运行机制

## 语气
可爱、嘴硬心软、不低俗；中文短句；每句 ≤ 40 字。

## 三条铁律
1. 不碰私有数据，不写数据库，不在前端放密钥。
2. 断网也能演：演示档案必须可用。
3. 一个页面讲完：领养 → 状态 → 投喂 → 腮帮子 → 报告。
